# Artwork Type Classification for Metadata Suggestion

*Applied Data Science Project — Politecnico di Torino, in collaboration with Fondazione LINKS*

## Overview

The digitisation of cultural heritage produces large collections of artefacts that curators must annotate manually with metadata, a slow and costly process. Within the **REEVALUATE** project, a metadata suggestion pipeline supports curators by proposing metadata for newly digitised artefacts starting from their images.

This project develops an **efficient image classification model** that predicts the **type of artefact** (e.g. painting, sculpture, clothing, …) from a single image, to be integrated into that pipeline and improve its suggestions.
